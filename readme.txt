Course: 15-112, Fundamentals of Programming and Computer Science
Institution: Carnegie Mellon University
Semester: Summer 2016
Project Grade: 92% (A)
Language: Python
Library: Tkinter

OVERVIEW

For my final term project in CMU's 15-112 course, I developed a Python-based recreation of Octagon, a 3D-style arcade game. Players navigate through an octagonal tunnel containing hallways, platforms, and gaps, with the objective of reaching the end before time runs out.

The game was implemented entirely in Python using Tkinter for its graphical interface and does not require any third-party libraries.

PROJECT DETAILS

- Game Development: Recreated the gameplay of Octagon, including navigation through an octagonal tunnel with various obstacles.
- Graphical Interface: Used Python's Tkinter library to implement the game's visual interface.
- Independent Implementation: Designed and developed the game as part of the course's independent term project requirement.

COURSE CONTEXT

15-112: Fundamentals of Programming and Computer Science is a rigorous introductory programming course at Carnegie Mellon University emphasizing problem-solving, program design, debugging, and computational efficiency using Python.

The term project provides an opportunity for students to independently design and implement a substantial Python application.
